How to Set Up the Bot

What you need:
A Pterodactyl panel with this egg installed 👉 https://github.com/stanislasbdx/pterodactyl-egg-discord
Don't have your own panel or hosting? No worries, just buy a bot hosting plan!

Steps:

1️⃣ Upload the bot file to "/home/container/" on your hosting.

2️⃣ Open "index.js" and scroll down to the 20-60 line:
"const TOKEN = process.env.TOKEN || 'YOUR_NEW_TOKEN_HERE';"

3️⃣ Replace "YOUR_NEW_TOKEN_HERE" with your bot token.

4️⃣ Search for "Tome • Core" in "index.js" and rename it to your own server name, like 
"FireMC • Core", "AppleMC • Core" or "DonutSMP • Core".

5️⃣ Save the file and hit Start ✅

🎥 Setup video + more help: https://www.youtube.com/@mrtome101

⚠️ Never share your bot token with anyone!
